# ResumeIQ Browser Extension (Manifest V3)

Allows capturing job postings directly from your authenticated browser session on login-walled sites (such as LinkedIn, Indeed, and Glassdoor) without server-side scraping.

## Load unpacked in Chrome / Edge

1. Open `chrome://extensions` (or `edge://extensions`).
2. Enable **Developer mode**.
3. Click **Load unpacked** and select this `apps/extension` folder.
4. Copy your ResumeIQ session token from **Settings → Browser Extension Token** in the web app and paste it into the extension popup.
5. Open any job posting and click **Add to ResumeIQ**.
